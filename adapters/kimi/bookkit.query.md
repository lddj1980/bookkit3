## Regras de Etiqueta
- Nunca submeta para o mesmo agente com livros diferentes ao mesmo tempo
- Se um agente pedir exclusividade, respeite o prazo combinado
- Respostas negativas não justificam resposta — salvo se pedirem feedback
- Personalize cada query — agentes identificam templates genéricos

## Próximos Passos

Após criar `bookkit/QUERY.md`, verifique a Lista de Submissão:

**Se a lista estiver vazia:**
→ Pesquise agentes e editoras para o gênero antes de enviar qualquer query
→ Personalize o parágrafo de abertura para cada destinatário antes de enviar

**Paralelamente:**
→ `/bookkit.press` — press kit completa o pacote de submissão
→ `/bookkit.launch` — planeje o lançamento independente do resultado das submissões

**Fluxo recomendado:**
1. Envie para 5-10 agentes por rodada (nunca todos de uma vez)
2. Aguarde respostas (6-12 semanas é o padrão)
3. Ajuste a query com base em feedbacks recebidos
4. Nova rodada se necessário

**Lembrete:** Submissão simultânea a múltiplos agentes é esperada e aceita.
Exclusividade só se um agente pedir explicitamente por escrito.
